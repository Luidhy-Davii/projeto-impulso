## 📖 Sobre o Projeto

**Impulso** é mais do que um site institucional; é uma plataforma web que traduz a identidade de uma comunidade. O projeto foi construído do zero para apresentar a agenda, os pilares do movimento e servir como uma vitrine digital para a marca de streetwear interna (Drop). 

A interface utiliza **Glassmorphism**, tipografia fluida (escala modular) e interações dinâmicas para criar uma experiência de usuário moderna e imersiva.

## ✨ Principais Funcionalidades

* **Animações de Alta Performance:** Utilização da biblioteca **GSAP** para efeitos de *reveal* no scroll e transições suaves.
* **Arquitetura CSS Avançada:** Estilização construída com **SCSS**, utilizando de forma pesada *Mixins*, *Variáveis* (Design Tokens) e aninhamento para um código limpo e de fácil manutenção.
* **Galeria Interativa de Streetwear:** Sistema de *Toggle Switch* (Frente/Costas) desenvolvido em Vanilla JS, permitindo a visualização dos produtos sem quebrar a rolagem da página no mobile.
* **Header Premium:** Navegação com desfoque de vidro (backdrop-filter) e menu mobile inteligente que responde às interações do usuário.
* **Design Responsivo (Mobile First):** Layout 100% adaptável, garantindo a mesma qualidade visual em smartphones, tablets e desktops.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Semântico e acessível.
* **SCSS (Sass):** Pré-processador CSS para arquitetura modular.
* **Vanilla JavaScript:** Lógica de interface, manipulação de DOM e interatividade.
* **GSAP (GreenSock):** Biblioteca de animações web.
* **Remix Icon / Phosphor Icons:** Bibliotecas de iconografia.
